# Modellazione API

## Panoramica di Lab

L’utilizzo delle API di Experience Platform è fondamentale per comprendere come automatizzare e rendere operative le varie funzioni della piattaforma. La definizione degli schemi e la comprensione del modo in cui i dati vengono descritti da tali schemi è una delle prime cose che un cliente farà su Adobe Experience Platform quando definirà la propria architettura dei dati.

Questo laboratorio illustra l’esperienza di progettazione dello schema di Adobe Experience Platform utilizzando solo le API. Scoprirai come creare schemi personalizzati utilizzando i componenti XDM esistenti, aggiungendo personalizzazioni in XDM e identificando e creando vari descrittori di identità da utilizzare con Real-Time Customer Profile.

## Obiettivi di apprendimento

Essere in grado di creare uno schema utilizzando solo le API di Experience Platform tramite una serie di componenti fondamentali XDM come:

1. Classi
1. Gruppi di campi
1. Descrittori
   1. Identità (inclusa quella primaria)
   2. Relazione
   3. Riferimento
