# Genera schema

## Assembly schema

Tutti gli schemi come parte di XDM sono composti nello stesso modo.  Uno schema è sempre composto da una sola classe e da uno o più gruppi di campi. Inoltre, la classe di uno schema determina il modo in cui gli altri sistemi all’interno di Experience Platform interpreteranno i dati (ovvero come una serie temporale o basata su record).

![Diagramma che mostra uno schema composto da una classe e da uno o più gruppi di campi](assets/overview-schema-assembly.jpeg "Assembly schema")
