# Profilo in azione

## Prerequisiti

>[!WARNING]
>
>Prima di avviare questo laboratorio, è necessario aver completato i seguenti laboratori

- [Installazione di Postman](../../postman-setup/postman-installation.md)

Se non hai completato queste esercitazioni, fallo adesso prima di continuare.

## Panoramica di Lab

Questo video illustra come questo laboratorio simula una visita a una pagina web da Edge Network a Adobe Experience Platform e come convaliderai il profilo risultante, la qualificazione dei segmenti e l’evento del data lake.

>[!VIDEO](https://video.tv.adobe.com/v/3491061/)

## Obiettivi di apprendimento

In questo esercizio simuleremo una visita a una pagina web da un’origine Edge a Adobe Experience Platform. Cosa devi fare dopo aver preso questo laboratorio?

- Creare e configurare uno stream di dati in Adobe Experience Platform
- Inviare un evento web di prova ad Edge Network tramite Postman
- Convalidare la creazione di profili e la qualificazione dei segmenti nel profilo in tempo reale
- Conferma l’esistenza del profilo su Edge ma non ancora nel set di dati Snapshot profilo
- Verifica che l’evento sia stato archiviato nel Data Lake
